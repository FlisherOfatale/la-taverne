# La Taverne 0.32.0-alpha

*2026-11-18*

## English

### New
- Join requests are confirmed: once the leader's addon has your request, the group shows "Request received". If the leader was offline, your request waits and is sent again when they're back, instead of getting lost.
- "Leader offline" on groups whose leader is offline.
- Minimap right-click menu: Open groups, My group (or Create a group), Auto-invite, and Start / Stop auto-invite.
- Options: the Error report section is always there ("No errors recorded." when empty), and the addon's version is shown at the bottom.

### Fixes
- A group's title cut with "..." now shows in full in its tooltip, with how long ago it was posted.
- Allied messages in the guild window (Communities) now show the time in front, like the other messages, when chat timestamps are on.
- Test mode: the test guild window's chat follows the "Show the guild tag on allied messages" option.

Players need this version on both sides for request confirmations; with an older leader, a request may be sent a second time.

## Français

### Nouveautés
- Les demandes pour rejoindre un groupe sont confirmées : dès que l'addon du chef a reçu votre demande, le groupe affiche « Demande reçue ». Si le chef était hors ligne, votre demande attend et est renvoyée à son retour, au lieu de se perdre.
- « Chef hors ligne » sur les groupes dont le chef est déconnecté.
- Menu du clic droit sur l'icône de la minicarte : Groupes ouverts, Mon groupe (ou Créer un groupe), Invitation automatique, et Lancer / Arrêter l'invitation automatique.
- Options : la section Rapport d'erreurs est toujours visible (« Aucune erreur enregistrée. » quand elle est vide), et la version de l'addon s'affiche en bas.

### Corrections
- Le titre d'un groupe coupé par « ... » s'affiche en entier dans son infobulle, avec depuis combien de temps il est publié.
- Les messages alliés dans la fenêtre de guilde (Communautés) affichent maintenant l'heure devant, comme les autres messages, quand l'horodatage du chat est activé.
- Mode test : le chat de la fenêtre de la guilde de test suit l'option « Afficher le tag de la guilde sur les messages alliés ».

Les confirmations de demande ont besoin de cette version des deux côtés ; avec un chef sur une version plus ancienne, une demande peut être envoyée une deuxième fois.

# La Taverne 1.3.2

*2026-11-25*

## English

### Fixes
- Allied guild chat in the game's chat window shows the lynx and the guild tag before the name again, and the name is a normal player link again (right-click menu, click to whisper). Since 1.3.1 the game took these lines for messages from the guild's Discord. Players using Chattynator weren't affected.

## Français

### Corrections
- Le chat des guildes alliées dans la fenêtre de chat du jeu affiche de nouveau le lynx et le tag de la guilde devant le nom, et le nom est de nouveau un lien de joueur normal (menu clic droit, clic pour chuchoter). Depuis la 1.3.1, le jeu prenait ces lignes pour des messages venant du Discord de la guilde. Les joueurs qui utilisent Chattynator n'étaient pas touchés.
